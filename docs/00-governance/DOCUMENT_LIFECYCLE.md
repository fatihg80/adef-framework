# Document Lifecycle

## States

`Draft → Review → Accepted → Superseded / Deprecated`

## Rules

- Drafts may contain unresolved assumptions.
- Accepted documents represent the current source of truth.
- Superseded documents should link to their replacement.
- Deprecated documents remain for traceability when history matters.
- Material changes should be reviewable through version control.

## Ownership

Assign an accountable owner for any artifact whose accuracy materially affects delivery, security, compliance, or operations.
