# Glossary

Use this file to define project-specific business and engineering terms so humans and AI agents interpret them consistently.

| Term | Definition | Notes |
|---|---|---|
| ADR | Architecture Decision Record | Captures a consequential architectural decision and its rationale. |
| TDD | Technical Design Document | Describes how a substantial technical change will be implemented. |
| PRD | Product Requirements Document | Describes the product problem, users, outcomes, and scope. |
| SRS | Software Requirements Specification | Defines software requirements in a structured, verifiable form. |
| C4 | Context, Containers, Components, Code | A hierarchical approach to software architecture diagrams. |
| NFR | Non-Functional Requirement | Defines quality constraints such as performance, security, reliability, and scalability. |
