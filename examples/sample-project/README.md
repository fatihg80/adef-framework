# Sample Project

This directory will contain a worked example showing how a real project adopts ADEF without filling every template.

The example should demonstrate:
- selecting a documentation profile,
- tracing product goals to requirements,
- recording architecture decisions,
- creating only useful technical designs,
- connecting contracts and acceptance criteria,
- carrying knowledge into deployment and operations,
- using `AGENTS.md` to guide AI-assisted implementation.

A complete worked example is planned for a later v0.1.x update.
